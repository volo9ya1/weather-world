# 🌦️ Мир Погоды (Weather World)

Интерактивное веб-приложение для отслеживания погоды в реальном времени с адаптивным дизайном и графическими спецэффектами.

---

## ✨ Основные возможности

* 📍 **Автоматическая геолокация:** Приложение автоматически определяет ваш город при входе.
* 🔍 **Поиск по городам:** Возможность узнать погоду в любой точке мира.
* 🎨 **Динамические темы:** Внешний вид приложения и задний фон меняются в зависимости от погоды (солнце, дождь, снег, облака, ночь).
* 🌧️ **Canvas-анимации:** Анимированный дождь, падающий снег и мерцающие звезды на фоне.
* 💡 **Умные рекомендации:** Виджет с советами о том, что надеть и стоит ли идти на прогулку.

---

## 🛠️ Технологии

* **HTML5** — структура и семантика
* **CSS3** — стили, стеклянный эффект (Glassmorphism), анимации
* **JavaScript (ES6+)** — логика работы, работа с API, Canvas API
* **OpenWeatherMap API** — получение актуальных данных о погоде

# 🌦️ Weather World

An interactive real-time weather web application featuring adaptive design and visual atmospheric effects.

---

## ✨ Key Features

* 📍 **Auto-Geolocation:** Automatically detects your current city upon launch.
* 🔍 **City Search:** Easily search for live weather conditions in any city worldwide.
* 🎨 **Dynamic Themes:** UI styles and backgrounds adapt dynamically based on weather conditions (sunny, rainy, snowy, cloudy, night).
* 🌧️ **Canvas Animations:** Smooth background animations featuring rain, falling snow, and twinkling stars.
* 💡 **Smart Recommendations:** A built-in widget offering personalized advice on what to wear and outdoor activity suitability.

---

## 🛠️ Tech Stack

* **HTML5** — Structure and semantics
* **CSS3** — Custom styling, Glassmorphism visual effects, animations
* **JavaScript (ES6+)** — Application logic, REST API integration, Canvas API
* **OpenWeatherMap API** — Live weather data fetching
