# 🌦️ Мир Погоды (Weather World)

Интерактивное веб-приложение для отслеживания погоды в реальном времени с адаптивным дизайном и графическими спецэффектами.

---

## ✨ Основные возможности

* 📍 **Автоматическая геолокация:** Приложение автоматически определяет ваш город при входе.
* 🔍 **Поиск по городам:** Возможность узнать погоду в любой точке мира.
* 🎨 **Динамические темы:** Внешний вид приложения и задний фон меняются в зависимости от погоды (солнце, дождь, снег, облака, ночь).
* 🌧️ **Canvas-анимации:** Анимированный дождь, падающий снег и мерцающие звезды на фоне.
* 💡 **Умные рекомендации:** Виджет с советами о том, что надеть и стоит ли идти на прогулку.

---

## 🛠️ Технологии

* **HTML5** — структура и семантика
* **CSS3** — стили, стеклянный эффект (Glassmorphism), анимации
* **JavaScript (ES6+)** — логика работы, работа с API, Canvas API
* **OpenWeatherMap API** — получение актуальных данных о погоде
